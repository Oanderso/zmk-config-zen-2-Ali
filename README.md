## TPS43 touchpad branch

The `feature/tps43-touchpad-inertia` branch adds an Azoteq TPS43/PXM0016
touchpad on the right half, using pins freed by removal of the right e-ink
screen. See [TPS43_TOUCHPAD.md](TPS43_TOUCHPAD.md) for wiring and momentum
tuning.
